# Figure Data CSVs

This directory contains the raw underlying data for each figure in the DQN trading paper.

---

## paper_figure1_data.csv
**Source:** `drl/dqn/reports/ensemble_table2/{asset}/top5_ensemble_R.npz` (DQN) and `baseline_run.py::compute_long_only_returns` (Long).

Cumulative portfolio returns over the 2011–2019 test period, scaled to `port_vol_target=0.97`.

| Column | Description |
|--------|-------------|
| `date` | Trading date (YYYY-MM-DD) |
| `asset` | Asset class: Commodity, Equity Index, Fixed Income, Forex |
| `DQN_cum_return` | Cumulative return of DQN Top-5 ensemble (additive, σ=0.97) |
| `Long_cum_return` | Cumulative return of Long-only baseline (additive, σ=0.97) |

---

## exhibit4_data.csv
**Source:** `drl/dqn/reports/per_contract/{asset}/{ticker}_s{seed}.npz`

Per-contract annualized Sharpe ratios for Exhibit 4 (boxplot).

| Column | Description |
|--------|-------------|
| `ticker` | Contract ticker symbol |
| `asset` | Asset class |
| `seed` | DQN seed (42–51) |
| `sharpe` | Annualized Sharpe ratio (`mean_daily * 252 / (std_daily * sqrt(252))`) |

## supp_rolling_sharpe_data.csv
**Source:** Same as Figure 1.

252-day rolling Sharpe ratio for both DQN and Long-only strategies.

| Column | Description |
|--------|-------------|
| `date` | Trading date (YYYY-MM-DD) |
| `asset` | Asset class |
| `DQN_sharpe` | Rolling 252-day DQN Sharpe (`mean/std * sqrt(252)`) |
| `Long_sharpe` | Rolling 252-day Long-only Sharpe |

First ~251 days are NaN (insufficient window).

---

## supp_drawdown_data.csv
**Source:** Same as Figure 1.

Drawdown in percent: `(wealth - peak) / peak * 100`.

| Column | Description |
|--------|-------------|
| `date` | Trading date (YYYY-MM-DD) |
| `asset` | Asset class |
| `DQN_drawdown` | DQN drawdown (%) |
| `Long_drawdown` | Long-only drawdown (%) |

Initial wealth = number of contracts in the portfolio.

## supp_monthly_heatmap_data.csv
**Source:** Same as Figure 1. Resampled to monthly using `resample('ME').sum()`.

Monthly summed returns per year-month per asset class.

| Column | Description |
|--------|-------------|
| `year` | Year (YYYY) |
| `month` | Month (1–12) |
| `asset` | Asset class |
| `DQN_return` | Sum of DQN daily returns for the month |
| `Long_return` | Sum of Long-only daily returns for the month |

---

## supp_yearly_bars_data.csv
**Source:** Same as Figure 1. Resampled to yearly using `resample('YE').apply(annual_sharpe)`.

Annualized Sharpe ratio per year per asset class.

| Column | Description |
|--------|-------------|
| `year` | Year (YYYY) |
| `asset` | Asset class |
| `DQN_return` | DQN annualized Sharpe (`mean/std * sqrt(252)`) |
| `Long_return` | Long-only annualized Sharpe |

## exhibit5_data.csv
**Source:** `drl/dqn/reports/ensemble_table2_bp/{asset}/bp{XX}/metrics.json` and `daily_costs.npz`

Transaction cost sensitivity: Sharpe ratio and average daily cost vs. BP level (basis points).

| Column | Description |
|--------|-------------|
| `bp_level` | Transaction cost level in basis points (e.g., 20 = 0.20 bps) |
| `asset` | Asset class |
| `sharpe` | Portfolio Sharpe ratio at this BP level |
| `avg_daily_cost` | Average daily cost per contract in dollars (NaN if not available) |

Currently only bp20 (0.20 bps) is available; other levels are pending Phase 1 backtest completion.
